description: Написать тесты ДО кода (test-first) для критичной задачи плана
argument-hint: <feature-name> <номер задачи>
---

Запусти агента `test-author`, чтобы написать тесты до реализации.

Аргументы (фича и номер задачи): $ARGUMENTS

Агент должен:
- прочитать пункт `impl-<feature-name>.md`, разделы §8 и §11 TDD, требования PRD;
- написать тесты по критериям приёмки (happy-path + edge/ошибки + security-кейсы);
- прогнать их и убедиться, что они **падают** (red-фаза).

Применять для задач, помеченных в плане как критичные. После — `/implement`,
который делает тесты зелёными, не меняя сами тесты.
