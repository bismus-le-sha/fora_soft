---
description: Реализовать одну задачу из Implementation Plan
argument-hint: <feature-name> <номер задачи>
---

Запусти агента `implementer`, чтобы реализовать одну задачу плана.

Аргументы (фича и номер задачи): $ARGUMENTS

Агент должен:
- прочитать пункт из `prds/<feature-name>/impl-<feature-name>.md`,
  соответствующие разделы TDD и требования PRD;
- реализовать строго эту задачу (в объёме одного будущего MR/PR);
- прогнать тесты/линт, отметить пункт плана как выполненный и закоммитить
  результат **локально** в feature-ветку.
- **НЕ делать `git push` и НЕ открывать PR.** PR — последний шаг, только
  после того, как код-ревью (и, если нужен, security-аудит) пройдены
  локально — см. корневой `CLAUDE.md` → «Git-флоу и Pull Requests».

Если номер задачи не указан — покажи невыполненные пункты плана и спроси, какой брать.
После завершения предложи запустить ревью агентом `code-reviewer`; push и
открытие PR — отдельный шаг после успешного ревью (и security-аудита, если
применимо).
