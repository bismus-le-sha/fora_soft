# security/

Продуктовая безопасность (сквозная, не привязана к одной фиче).

- `security-baseline.md` — базовая модель угроз продукта: активы, границы доверия,
  угрозы (STRIDE), модель аутентификации/авторизации, защита данных, зависимости
  и **чек-лист требований**, которым обязан удовлетворять каждый TDD и каждый PR.
  Генерируется агентом `security-auditor` командой `/threat-model` (разово, до `/design`).
- Аудиты реализаций проводит тот же агент командой `/security-audit` (перед мержем).

Per-feature специфика безопасности живёт в разделе 10 соответствующего TDD и
опирается на этот baseline.
